# Pomodoro allocation preview

1. If Countdown is Compact, click it to open the normal window.
2. Right-click the normal circle. Under **Timer Mode**, select **Pomodoro**. The menu marks the selected timer mode.
3. The circle shows 5 minutes of break in blue, then 25 minutes of focus in green. Each minute is 6 degrees. The unused half keeps the Countdown background color.
4. **Focus** identifies the first phase. The pair is ready. The accessible description gives both allocations without use of color.
5. To return, right-click and select **Countdown**. A Countdown that was running is paused at the mode change. Select **Resume** to continue it.

This feature is an allocation preview in the normal window. Timing controls, duration edits, Compact Pomodoro, and saved mode/durations are separate features. The preview has no Start, Pause, Reset, or scroll controls. Countdown settings and next-hour actions apply only to Countdown. Mode selection does not change those settings.
